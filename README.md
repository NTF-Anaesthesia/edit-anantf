# edit.anantf.com

Shortcut to the NTF Anaesthesia page editor. Put `edit.` in front of any anantf.com address:

`anantf.com/spinal/` → `edit.anantf.com/spinal/` opens `https://anantf.com/edit.html?page=/spinal/`.

`index.html` and `404.html` are the same redirect (GitHub Pages serves `404.html` for every other path).
The editor itself lives in NTF-Anaesthesia/anantf-site; it has to stay on anantf.com to edit those pages.

Pages that moved to their own repo and address (regional.anantf.com, mo.anantf.com, ot.anantf.com; the `MOVED` list at
the top of both files) can't be edited here: the shortcut shows the new address and a link to open an issue in that
repo (NTF-Anaesthesia/regional, mo or ot).
